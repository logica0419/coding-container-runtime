# 5. cgroup

コンテナを同じホスト上でいくつも動かすためには、コンテナ同士がコンピューターの**リソースを食い合って**しまう問題を防ぐ必要があります。  
5章では、プロセスの**リソースを制限**するための技術、**cgroup**関連処理を実装していきます。

この章で触るファイル: `cgroup.go`
